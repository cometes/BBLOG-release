# BBLOG

FGO(Fate/Grand Order)의 스토리를 한글로 감상할 수 있게 도와주는 안드로이드 앱이에요.

## 뭐가 되나요

- **스토리 리더**: 이벤트/메인 스토리 챕터를 골라 앱 안에서 바로 읽을 수 있어요.
  - 한국 서버에 이미 정식 출시된 스토리는 공식 한글 번역을 그대로 보여줘요.
  - 아직 한국에 출시되지 않은 스토리는 Gemini AI로 직접 번역해서 보여줘요.
- **게임 화면 위 실시간 오버레이**: 인게임(일본 서버)으로 직접 플레이하면서도, 게임 화면 위에
  번역 자막을 띄워 따라갈 수 있어요. 대사창을 자동으로 인식해서 알아서 다음 줄로 넘어가요.
- **커뮤니티 번역 공유**: 다른 사람이 이미 번역해둔 챕터가 있다면 직접 번역하지 않고 가져와서
  바로 읽을 수 있어요.

## 설치 방법

1. 아래 [Releases](../../releases)에서 최신 APK 파일을 다운로드하세요.
2. 안드로이드에서 "출처를 알 수 없는 앱 설치"를 허용해야 설치할 수 있어요.
3. 설치 후 첫 실행 시 튜토리얼을 따라가면 필요한 권한과 설정을 안내해드려요.

## 참고

- 직접 번역 기능을 쓰려면 본인의 Google Gemini API 키가 필요해요 (무료 발급 가능, 사용량에
  따라 소액 비용이 발생할 수 있어요). 튜토리얼이나 설정 화면에서 언제든 등록할 수 있고, 등록하지
  않아도 이미 번역된 스토리는 그대로 읽을 수 있어요.
- 게임 화면 위 오버레이의 자동 대사 인식(자동 진행)은 Android 14 QPR2 이상에서만 지원돼요. 그 이전
  버전에서는 오버레이 자체는 정상 동작하고, 대사 넘기기만 수동(이전/다음 버튼)으로 하면 돼요.
- 이 저장소는 릴리스(설치 파일) 배포 전용이에요.
